## Overview

A self-built, mobile-friendly study app to prepare for the Fontys Neuromarketing MCQ exam, covering all six lectures with summaries, key terms, flashcards, quizzes, exam tips and a full mock-exam mode. **Live on GitHub Pages.**

<Callout>
Role: student & product owner. I provided the lecture materials, directed every design decision, tested on mobile, and deployed the final product, an AI-assisted build.
</Callout>

## Goal

Turn six lecture decks and a study guide into one reliable, self-contained tool I could revise from on any device.

## What I Built

A single-file HTML/CSS/JS app with per-lecture summaries, flashcards, quizzes, and a complete mock-exam mode, linked to a detailed PDF study guide for deeper reference, fully responsive across desktop and mobile.

## Process

I uploaded the six decks and study guide, reviewed and guided improvements across iterations (mobile navigation, PDF linking, content accuracy), then deployed and maintained the site on GitHub Pages.

## Results

A live, interactive, fully responsive study website used for real exam preparation, turning raw slides into structured, interactive learning material.

## Lessons Learned

Building the tool deepened my own understanding, and taught me practical web deployment with GitHub Pages.

## Technologies

HTML/CSS/JavaScript (single-file app), Claude AI, GitHub Pages. **Live site available.**
