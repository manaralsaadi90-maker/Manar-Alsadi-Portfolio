## Overview

A personal, offline-capable web app to master the full official **A2 + B1** Dutch vocabulary behind the NT2 state exam, built for one learner (Arabic-native, English-fluent) rather than a general product.

<Callout>
Role: product owner and project lead. I defined the concept, requirements and design constraints, made all product decisions, prioritised features, and did the real-world testing and QA, including catching a mobile bug that only hands-on use would reveal. AI-assisted build.
</Callout>

## Goal

A lightweight, offline-first flashcard app covering the complete LINK+ A2+B1 word lists, tailored to how I actually study.

## What I Built (directed)

A single self-contained HTML file (vanilla HTML/CSS/JS, no frameworks) covering all **3,409 words**, each with English, Arabic and a Dutch example sentence, plus **764 auto-generated verb conjugations** (present, past, perfect), grade-before-reveal flashcards, search/filter, custom words, dictionary links, browser text-to-speech pronunciation, dark mode, and offline backup/restore.

## Constraints & QA

I set clear constraints ("simplest solution wins," offline-first), curated the official source PDFs, drove the trilingual translation, specified features one at a time, and tested on desktop and phone, reporting precise bugs (e.g. the "My words" section freezing on mobile) and verifying fixes.

## Results

A working, mobile-friendly, offline trainer covering the full A2+B1 vocabulary with progress tracking, a tool I use for my own Dutch (NT2 B1) preparation.

<Callout>
Honesty note: translations and conjugations are AI-generated best-effort (not from an authoritative bilingual dictionary), which is why the app includes an edit function for verification.
</Callout>

## Lessons Learned

Clear constraints and hands-on testing beat feature lists, and building your own learning tool is a powerful way to learn.
