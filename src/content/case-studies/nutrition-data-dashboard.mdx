## Overview

An interactive dashboard that visualises product-nutrition data in a clear, engaging way, letting users compare products and understand nutritional value through real-life context (e.g. comparing a product to eggs or milk).

## Problem

Raw nutrition numbers on packaging are hard to interpret. The goal was to make the data understandable and comparable through interaction and storytelling.

## Research & Data Work

I extracted and structured nutritional data from product images and sources, then processed and organised the datasets, applying filtering, sorting and transformation so the data was ready to visualise, and building comparative logic between products and everyday foods.

## UX Decisions

I focused on clarity and engagement: dynamic charts with filtering and sorting, an interactive product gallery, and a 3D visualization to make exploration more tangible. Real-life comparisons turned abstract numbers into something relatable.

## Development

Built with **HTML, CSS and JavaScript**, using **Chart.js** for the charts and **Three.js** for 3D visualization, with AI-assisted development (ChatGPT for structuring, Cursor for debugging and optimisation) and Excel for data prep.

## Challenges & Solutions

Turning inconsistent source data into a clean dataset was the first hurdle, solved with a structured cleaning step. Based on user feedback at an exhibition, I replaced a static output with an interactive pop-up comparison to reduce effort.

## Results

Delivered a fully functional interactive dashboard, showcased at an exhibition, with UX improvements driven directly by user feedback and clearer data through visual storytelling.

## Lessons Learned

Good data visualization is editing, not decoration, the value is in making one comparison instantly clear.
